04 — THE DEMAND PROBLEM

AI Is Changing Memory Demand

More AI → More GPUs → More Memory

AI data centres require large quantities of specialised memory. As companies build more AI infrastructure, semiconductor manufacturers have to produce more memory products for these systems.

This creates pressure throughout the memory supply chain. Manufacturing capacity, advanced packaging and raw materials all become important factors.

AI / Server RAM is used as a proxy for AI-infrastructure memory demand. 2025–2026 values are estimates.
