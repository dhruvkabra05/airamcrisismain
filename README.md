# RAM Crisis — AI and the Future of Memory

A multi-page educational website that explains the growing demand for computer memory due to Artificial Intelligence and modern computing.

## 🌐 Live Website

**RAM Crisis:** https://ramcrisis10pages.vercel.app/

---

## 📌 About the Project

Artificial Intelligence is developing rapidly, and modern AI systems require a large amount of hardware resources. One of the important components affected by this growth is **memory (RAM)**.

This project explains the relationship between AI and memory demand in a simple and visual way. It covers the basics of RAM, different types of memory used in modern systems, the effect of AI on memory demand, supply-chain challenges, and possible future developments.

The website is designed as a **college-level educational project** with multiple pages and visual information.

---

## 🎯 Objectives

The main objectives of this project are:

* To understand the basics of RAM and computer memory.
* To explain why AI systems require large amounts of memory.
* To understand the difference between DRAM and HBM.
* To study the increasing demand for memory caused by AI.
* To understand the impact of increasing memory demand on the hardware industry.
* To explore memory supply-chain challenges.
* To present information using charts and visual elements.
* To discuss possible future developments in the memory industry.

## 📊 Key Topics Covered

### 1. RAM

The project introduces RAM and explains its importance in computer systems.

### 2. AI and Memory

Modern AI applications process large amounts of data and therefore require high memory capacity and bandwidth.

### 3. DRAM and HBM

The project introduces two important memory technologies:

* **DRAM** — widely used as system memory.
* **HBM (High Bandwidth Memory)** — designed to provide very high memory bandwidth and is commonly associated with high-performance computing and AI accelerators.

### 4. Increasing Demand

The project explains how the rapid development of AI infrastructure can increase demand for advanced memory technologies.

### 5. Supply Chain

The website discusses how memory production depends on semiconductor manufacturing, specialized technologies, and supply chains.

### 6. Future of Memory

The final section explores how memory technologies may continue developing as AI and high-performance computing grow.
